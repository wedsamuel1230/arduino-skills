# Common Board and Module Dimensions

Use this reference only for rough starting values. Real measurements from the
user or datasheet should override these numbers.

## Arduino Family

- Arduino Uno: about 68.6 mm x 53.4 mm
- Arduino Nano: about 45 mm x 18 mm

## ESP32 Family

- ESP32 DevKit variants differ. Measure the exact module, especially width,
  antenna keepout, and USB connector height.

## RP2040 Family

- Raspberry Pi Pico: about 51 mm x 21 mm

## Common Modules

Collect the exact dimensions for:

- displays
- relay boards
- battery holders
- terminal blocks
- sensor breakout boards

Module dimensions drift more than board-family names suggest. Treat online
tables as approximate unless the exact part number matches.
