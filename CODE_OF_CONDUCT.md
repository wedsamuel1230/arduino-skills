# Contributor Covenant Code of Conduct

## Our Pledge

We are committed to providing a welcoming and inspiring community for all. We pledge that everyone participating in the Arduino Skills community and its projects will experience a harassment-free environment, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our Standards

Examples of behavior that contributes to creating a positive environment include:

- Being respectful and inclusive of different viewpoints
- Using welcoming and inclusive language
- Providing constructive and kind feedback
- Focusing on what is best for the community
- Showing empathy towards others
- Helping others learn and grow

Examples of unacceptable behavior include:

- Harassment, intimidation, or discrimination
- Insulting or derogatory comments
- Personal attacks
- Unwelcome sexual attention
- Publishing private information without consent
- Trolling or spam
- Any conduct that could reasonably be considered inappropriate in a professional setting

## Enforcement

Community leaders are responsible for:
- Clarifying and enforcing our standards of conduct
- Taking appropriate action in response to unacceptable behavior
- Maintaining the confidentiality of reporters

Violations can be reported to the community leaders via:
- **GitHub Issues:** For non-sensitive matters ([report issue](../../issues/new))
- **Private communication:** For sensitive matters (email the project maintainer)

## Scope

This Code of Conduct applies to all community interactions related to Arduino Skills, including:
- GitHub repositories
- Pull requests and code reviews
- Issue discussions
- Emails and direct messages about the project
- Community forums and channels

## Attribution

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.0.

For questions about this Code of Conduct, please file an issue with the `[conduct]` label.
