# arduino-skills v1.6.0

Release date: 2026-08-11

## Highlights

- Adds four source-backed board profiles, bringing the indexed reference set to
  nine boards: Mega 2560 Rev3, Nano Every, Nano ESP32, and ESP32-C3-DevKitC-02.
- Makes `embedded-project-loop` the recommended first skill for physical,
  recovery, measurement, and multi-session work.
- Adds `loop-engine-evidence-contract`, an executable evaluation with complete
  and incomplete durable-loop fixtures.
- Keeps one shared `skills/` source of truth across Agent Skills CLI, Codex,
  Claude Code, and Cursor adapters.
- Preserves the raw ordered `constexpr int` pin convention and C/C++
  embedded-first guidance.

## Verification

- 28 active skills pass structural validation.
- 9 board profiles pass board-reference validation.
- 8/8 shared contract themes pass.
- 11/11 forward-contract eval cases pass after the loop-eval addition.
- Official Codex plugin validation, Python syntax, JSON parsing, and diff checks
  pass.

## Evidence boundary

This release has repository and documentation evidence only. No board was
wired, flashed, uploaded to, measured, system-tested, or deployed in this
release loop. Model-level semantic triggering remains outside the deterministic
harness, and the prior fresh-context reviewer artifact remains unavailable.
